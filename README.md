# Лабораторна робота 1. Реалізація та перевірка зворотного поширення похибки

## 1. Запуск та відтворення результатів

Для відтворення обох реалізацій (правильної та з навмисною помилкою) використовується пакетний менеджер `uv` із зафіксованими залежностями.

Встановлення середовища та залежностей:

```bash
python -m pip install uv
python -m uv pip install -r requirements.txt
```

Команди запуску:

- Правильна реалізація:
  ```bash
  python -m uv run main.py
  ```

- Дослід із навмисною помилкою:
  ```bash
  python -m uv run main.py --simulate-error
  ```

### Дані та ініціалізація параметрів

Усі значення в звіті відтворюються завдяки фіксованим генераторам випадкових чисел (`numpy.random.default_rng(0)`) і розрахункам у `float64`.

Дані. Використовується набір Iris (150 об’єктів, 4 ознаки, 3 класи).
- Розбиття стратифіковане: для кожного класу (0, 1, 2) індекси перемішуються генератором `default_rng(0)` (один генератор послідовно для всіх трьох класів), після чого перші 35 об’єктів йдуть у навчальну вибірку, решта 15 у тестову.
- Отримуємо навчальну вибірку з $N=105$ об’єктів (по 35 на клас) і тестову з 45 об’єктів. Тестова вибірка в цій роботі не використовується.
- Ознаки стандартизуються: середнє та стандартне відхилення (`ddof=0`) обчислюються лише за навчальною вибіркою і застосовуються до обох вибірок:

$$x' = \frac{x - \mu_{\text{train}}}{\sigma_{\text{train}}}$$

**Ініціалізація ваг.** Генератор `default_rng(0)` створюється заново, після чого послідовно (у вказаному порядку) генеруються:

| Параметр | Розмірність | Розподіл |
|----------|-------------|----------|
| $W_1$ | $4 \times 8$ | $\mathcal{N}(0,\sigma^2)$, $\sigma=\sqrt{2/4}$ (ініціалізація He) |
| $b_1$ | $8$ | нулі |
| $W_2$ | $8 \times 3$ | $\mathcal{N}(0,\sigma^2)$, $\sigma=\sqrt{2/(8+3)}$ (ініціалізація Glorot) |
| $b_2$ | $3$ | нулі |

Ці самі початкові значення копіюються в реалізацію на PyTorch (з транспонуванням для `nn.Linear`), тому обидві моделі стартують з ідентичних параметрів.

## 2. Формули зворотного проходу та розмірності

Для основних перевірок використовується повна навчальна вибірка, тому кількість об’єктів у батчі $N=105$.

Архітектура мережі:

$$X \to \mathrm{Linear}(4,8) \to \mathrm{ReLU} \to \mathrm{Linear}(8,3)$$

Позначення:
- $Y$ - one-hot матриця правильних відповідей;
- $P$ - матриця ймовірностей (результат softmax).

### Збережені проміжні значення

Значення, які зберігаються під час прямого проходу для уникнення повторних обчислень при зворотному проході:

| Змінна | Розмірність | Призначення |
|--------|-------------|-------------|
| $X$ | $105 \times 4$ | Вхідні дані, потрібні для розрахунку $dW^{(1)}$ |
| $Z^{(1)}$ | $105 \times 8$ | Значення до активації, потрібні для похідної ReLU |
| $A^{(1)}$ | $105 \times 8$ | Значення після ReLU, потрібні для розрахунку $dW^{(2)}$ |
| $y$, $P$ | $105$, $105 \times 3$ | Потрібні для обчислення початкового градієнта за логітами |

### Формули та розмірності градієнтів

Градієнт за логітами $Z^{(2)}$. Функція втрат є усередненою за об’єктами:

$$dZ^{(2)} = \frac{1}{N}(P - Y)$$

Розмірність: $105 \times 3$.

Градієнти другого шару ($W_2$ та $b_2$):

$$dW^{(2)} = (A^{(1)})^\top dZ^{(2)}$$

Розмірність $dW^{(2)}$: $8 \times 3$.

$$db^{(2)} = \sum_{i=1}^{N} dZ^{(2)}_i$$

Розмірність $db^{(2)}$: $3$.

Градієнт по входу другого шару ($A^{(1)}$):

$$dA^{(1)} = dZ^{(2)} (W^{(2)})^\top$$

Розмірність: $105 \times 8$.

Градієнт ReLU ($Z^{(1)}$). Похідна ReLU дорівнює 1 при $Z^{(1)} > 0$ і 0 інакше:

$$dZ^{(1)} = dA^{(1)} \odot \mathbb{I}(Z^{(1)} > 0)$$

Розмірність: $105 \times 8$.

Градієнти першого шару ($W_1$ та $b_1$):

$$dW^{(1)} = X^\top dZ^{(1)}$$

Розмірність $dW^{(1)}$: $4 \times 8$.

$$db^{(1)} = \sum_{i=1}^{N} dZ^{(1)}_i$$

Розмірність $db^{(1)}$: $8$.

## 5. Дослід із навмисною помилкою

У досліді тимчасово прибрано ділення на кількість об’єктів $N$ у градієнті за логітами. Функція втрат залишилася незмінною, оновлення ваг між порівняннями не виконувалося.

### Прогноз перед запуском

1. Чи зміниться втрата на тих самих параметрах?
   Ні, не зміниться, оскільки прямий прохід і обчислення функції втрат не змінювалися.

2. Як зміняться ненульові градієнти?
   Усі ручні градієнти збільшаться рівно в $N=105$ разів, бо тепер обчислюється сума градієнтів батчу, а не їхнє середнє.

3. Які перевірки мають виявити помилку?
   Обидві перевірки (звірка з PyTorch і чисельне диференціювання), оскільки еталонні методи продовжують обчислювати градієнт на основі усередненої втрати.

### Результати досліду

Прогноз повністю підтвердився. Відношення помилкового ручного градієнта до еталонного склало $\approx 105$, що підтверджує виявлення помилки масштабування.

## 6. Висновки

1. Ручна реалізація зворотного проходу в NumPy правильна. Втрата та всі елементи чотирьох градієнтів збігаються з PyTorch autograd із точністю близько $10^{-16}$, що значно краще за критерій $10^{-12}$. Для чисельного диференціювання різниці становлять близько $10^{-10}$, що також значно менше за поріг $10^{-7}$. Така точність відповідає межі, яку задає похибка округлення float64 при діленні на $2\varepsilon=2\cdot10^{-6}$.

2. Дослід із навмисною помилкою показав, що пропущене ділення на $N$ не впливає на пряму частину: значення втрати збігається з PyTorch ($2.22\times10^{-16}$, перевірку пройдено). Помилка проявляється лише в градієнтах. Усі вони збільшилися в $N=105$ разів, і обидві перевірки (з PyTorch та чисельна) це виявили. Звідси випливає, що порівняння самої втрати не здатне виявити помилку у зворотному проході, потрібно перевіряти градієнти.

3. Фактичні результати досліду збіглися з прогнозом, записаним до запуску, за всіма трьома пунктами.
