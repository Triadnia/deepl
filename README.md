# Лабораторна робота 1. Реалізація та перевірка зворотного поширення похибки

## 1. Запуск та відтворення результатів

Для відтворення обох реалізацій (правильної та з навмисною помилкою) використовується пакетний менеджер `uv` із зафіксованими залежностями.

Встановлення середовища та залежностей:

```bash
python -m pip install uv
python -m uv pip install -r requirements.txt
```

Команди запуску:

- Правильна реалізація:
  ```bash
  python -m uv run main.py
  ```

- Дослід із навмисною помилкою:
  ```bash
  python -m uv run main.py --simulate-error
  ```

## 2. Формули зворотного проходу та розмірності

Для основних перевірок використовується повна навчальна вибірка, тому кількість об’єктів у батчі \( N = 105 \).

Архітектура мережі: 
$\[ X \to \operatorname{Linear}(4, 8) \to \operatorname{ReLU} \to \operatorname{Linear}(8, 3) \]$

Позначення:
- \( Y \) це one-hot матриця правильних відповідей;
- \( P \) це матриця ймовірностей (результат softmax).

### Збережені проміжні значення

Значення, які зберігаються під час прямого проходу для уникнення повторних обчислень при зворотному проході:

| Змінна | Розмірність | Призначення |
|--------|-------------|-------------|
| \( X \) | \( 105 \times 4 \) | Вхідні дані, потрібні для розрахунку \( dW^{(1)} \) |
| \( Z^{(1)} \) | \( 105 \times 8 \) | Значення до активації, потрібні для похідної ReLU |
| \( A^{(1)} \) | \( 105 \times 8 \) | Значення після ReLU, потрібні для розрахунку \( dW^{(2)} \) |
| \( y \), \( P \) | \( 105 \), \( 105 \times 3 \) | Потрібні для обчислення початкового градієнта за логітами |

### Формули та розмірності градієнтів

Градієнт за логітами \( Z^{(2)} \):

Функція втрат є усередненою за об’єктами:
\[
dZ^{(2)} = \frac{1}{N}(P - Y)
\]
Розмірність: \( 105 \times 3 \).

Градієнти другого шару (\( W_2 \) та \( b_2 \)):
\[
dW^{(2)} = (A^{(1)})^\top dZ^{(2)}
\]
Розмірність \( dW^{(2)} \): \( 8 \times 3 \).

\[
db^{(2)} = \sum_{i=1}^{N} dZ^{(2)}_i
\]
Розмірність \( db^{(2)} \): \( 3 \).

Градієнт по входу другого шару (\( A^{(1)} \)):
\[
dA^{(1)} = dZ^{(2)} (W^{(2)})^\top
\]
Розмірність: \( 105 \times 8 \).

Градієнт ReLU (\( Z^{(1)} \)):

Похідна ReLU дорівнює 1 при \( Z^{(1)} > 0 \) і 0 інакше:
\[
dZ^{(1)} = dA^{(1)} \odot \mathbb{I}(Z^{(1)} > 0)
\]
Розмірність: \( 105 \times 8 \).

Градієнти першого шару (\( W_1 \) та \( b_1 \)):
\[
dW^{(1)} = X^\top dZ^{(1)}
\]
Розмірність \( dW^{(1)} \): \( 4 \times 8 \).

\[
db^{(1)} = \sum_{i=1}^{N} dZ^{(1)}_i
\]
Розмірність \( db^{(1)} \): \( 8 \).

## 5. Дослід із навмисною помилкою

У досліді тимчасово прибрано ділення на кількість об’єктів \( N \) у градієнті за логітами. Функція втрат залишилася незмінною, оновлення ваг між порівняннями не виконувалося.

### Прогноз перед запуском

1. Чи зміниться втрата на тих самих параметрах?
   Ні, не зміниться, оскільки прямий прохід і обчислення функції втрат не змінювалися.

2. Як зміняться ненульові градієнти?
   Усі ручні градієнти збільшаться рівно в \( N = 105 \) разів, бо тепер обчислюється сума градієнтів батчу, а не їхнє середнє.

3. Які перевірки мають виявити помилку?
   Обидві перевірки (звірка з PyTorch і чисельне диференціювання), оскільки еталонні методи продовжують обчислювати градієнт на основі усередненої втрати.

### Результати досліду

Прогноз повністю підтвердився. Відношення помилкового ручного градієнта до еталонного склало \( \approx 105 \), що підтверджує виявлення помилки масштабування.
